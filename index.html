verified

Conhecimentos fundamentais de IA, ML e IA generativa (conceitos, casos de uso e serviços AWS), com foco conceitual/estratégico.

quiz

Prova com ~65 questões e 90 minutos (nível Foundational).

insights

Técnicas que permitem aprender padrões a partir de dados para prever/classificar/decidir sem regras explícitas para cada caso.

auto_awesome

IA capaz de gerar conteúdo novo (texto/imagem/áudio/código) com base em padrões aprendidos em grandes volumes de dados.

model_training

Modelos grandes pré-treinados (ex.: LLMs) que podem ser adaptados para múltiplas tarefas (via prompt, fine-tuning, RAG, etc.).

scatter_plot

Representações vetoriais de texto/imagem que capturam similaridade semântica; usados em busca semântica, clustering, recomendação e RAG.

library_books

Técnica que “anexa” contexto recuperado (docs/KB) ao prompt para reduzir alucinação e responder usando fontes atualizadas.

hub

Plataforma para construir, treinar, ajustar e implantar modelos de ML, suportando pipelines/MLOps e endpoints gerenciados.

cloud

Serviço gerenciado para consumir Foundation Models via API (chat, embeddings, etc.) e construir apps GenAI com governança.

policy

Redução de viés, transparência, explicabilidade, privacidade, segurança e avaliação de impacto/risco ao longo do ciclo de vida.

security

Controle de acesso (IAM), criptografia, segregação de dados, proteção de PII, auditoria/logs e políticas de retenção/compliance.

tune

RAG com fontes confiáveis, prompt com instruções/limites, validação pós-resposta, grounded answers e observabilidade.
